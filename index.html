Laboratorio de Bases de Datos en Desarrollo Web

Compara en tiempo real los dos paradigmas principales para conectar una aplicación web a una base de datos: Enfoque Tradicional (Backend con Express + SQLite) frente a BaaS en la Nube (Backend-as-a-Service con Supabase).

Enfoque Tradicional

Node.js + Express + SQLite

El navegador no tiene acceso directo a la base de datos por seguridad. Construimos nuestro propio servidor API REST que procesa las peticiones y ejecuta sentencias SQL locales.

Frontend (fetch) → API REST (Express) → database.sqlite
  • Control Total: Tú diseñas la lógica, seguridad y middlewares.
  • Base de datos local: SQLite es un solo archivo embebido y ligero.
  • Independencia: No dependes de servicios ni cuotas de terceros.
  • Desafío para alumnos: Requiere configurar y correr un servidor local.
Enfoque Moderno (BaaS)

Supabase (Backend-as-a-Service)

Supabase provee una base de datos PostgreSQL en la nube y genera automáticamente APIs REST y WebSockets en tiempo real, interactuando directamente desde el navegador mediante un SDK.

Frontend (SDK JS) → Supabase Cloud (PostgreSQL)
  • Sin servidor que programar: Listo en minutos mediante CDN.
  • Dashboard visual: Los estudiantes ven tablas y filas en el navegador.
  • Tiempo Real Nativo: WebSockets sin necesidad de configurar Socket.io.
  • Desafío para alumnos: Dependencia de conectividad a Internet y políticas RLS.

// ========================================================
// 1. BACKEND TRADICIONAL CON NODE.JS + EXPRESS + SQLITE
// ========================================================
const express = require('express');
const sqlite3 = require('sqlite3').verbose();
const app = express();

app.use(express.json());

// Conectar o crear base de datos local
const db = new sqlite3.Database('./database.sqlite');

// Crear tabla
db.run(`CREATE TABLE IF NOT EXISTS estudiantes (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  nombre TEXT,
  email TEXT
)`);

// Endpoint GET
app.get('/api/estudiantes', (req, res) => {
  db.all('SELECT * FROM estudiantes ORDER BY id DESC', [], (err, rows) => {
    res.json(rows);
  });
});

// Endpoint POST
app.post('/api/estudiantes', (req, res) => {
  const { nombre, email } = req.body;
  db.run('INSERT INTO estudiantes (nombre, email) VALUES (?, ?)', [nombre, email], function(err) {
    res.status(201).json({ id: this.lastID, nombre, email });
  });
});

app.listen(3000, () => console.log('Servidor en http://localhost:3000'));
// ========================================================
// 2. CONSUMO DESDE EL FRONTEND (PETICIONES HTTP REST)
// ========================================================

// Leer registros (GET)
async function obtenerEstudiantes() {
  const respuesta = await fetch('/api/estudiantes');
  const datos = await respuesta.json();
  console.log('Estudiantes recibidos:', datos);
}

// Guardar nuevo registro (POST)
async function guardarEstudiante(nombre, email) {
  const respuesta = await fetch('/api/estudiantes', {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify({ nombre, email })
  });
  const resultado = await respuesta.json();
  console.log('Guardado con ID:', resultado.id);
}
// ========================================================
// 3. ENFOQUE BaaS: CONSUMO DIRECTO CON EL SDK DE SUPABASE
// ========================================================
// Importado vía CDN: <script src="https://cdn.jsdelivr.net/npm/@supabase/supabase-js@2"></script>

const supabase = window.supabase.createClient('https://tu-proyecto.supabase.co', 'tu-anon-key');

// Guardar registro (INSERT directo en PostgreSQL Cloud)
async function guardarEstudiante(nombre, email) {
  const { data, error } = await supabase
    .from('estudiantes_lab')
    .insert([{ nombre, email }]);
}

// Leer registros (SELECT directo)
async function obtenerEstudiantes() {
  const { data, error } = await supabase
    .from('estudiantes_lab')
    .select('*')
    .order('id', { ascending: false });
}

// Suscripción en Tiempo Real (Realtime)
supabase
  .channel('cambios-estudiantes')
  .on('postgres_changes', { event: '*', schema: 'public', table: 'estudiantes_lab' }, () => {
    obtenerEstudiantes(); // Se actualiza solo en todos los navegadores
  })
  .subscribe();
